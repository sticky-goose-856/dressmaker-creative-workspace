# Dressmaker Creative Workspace — feature reference

Dressmaker Creative Workspace groups project groups, design notes, and workspace profiles in a single workspace. Each section keeps its controls and related settings together.

| Section | Description |
|---|---|
| Project groups | A dedicated section for project groups and the configuration details associated with that area. |
| Design notes | A dedicated section for design notes and the configuration details associated with that area. |
| Workspace profiles | Related settings collected into named groups for a clearer configuration workflow. |

The project page follows the same section structure.
